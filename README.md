# Сложно сосредоточиться

Проектная работа четвёртого спринта Яндекс Практикума. Адаптивный сайт о том, почему бывает сложно сосредоточиться и какие способы помогают улучшить концентрацию внимания.

## Особенности проекта

- Семантическая HTML-разметка.
- Адаптивная вёрстка по принципу Mobile First с медиазапросами для 768 и 1024 px.
- Использование CSS Grid и Flexbox для расположения элементов.
- Светлая, тёмная и автоматическая темы оформления.
- CSS-переменные и `prefers-color-scheme` для настройки цветовых тем.
- Адаптивные размеры заголовков с помощью `clamp()`.
- Галерея изображений с ленивой загрузкой.
- Стилизация состояний кнопок и ссылок при наведении и фокусе.

## Структура проекта

- `index.html` — разметка страницы.
- `styles/` — основные стили, переменные и цветовые темы.
- `images/` — изображения и иконки.
- `fonts/` — шрифты.
- `scripts/` — скрипт переключения тем.

## Запуск проекта

Для просмотра сайта достаточно открыть файл `index.html` в браузере или запустить его через Live Server в VS Code.
